Este repositório consolida implementações em C puro focadas em estruturas de controle de fluxo, álgebra matricial e lógica condicional avançada, divididas em três frentes:

* **Simulação Vetorial de Movimentos no Xadrez:** Mapeamento espacial de regras de movimentação utilizando laços determinísticos (`for`, `while`, `do-while`), iterações aninhadas para trajetórias não lineares (como o movimento em "L") e algoritmos recursivos para validação de limites do tabuleiro.
* **Álgebra Matricial Aplicada (Batalha Naval):** Modelagem de grade bidimensional ($10 \times 10$) para controle de estados, varredura geométrica de coordenadas e cálculo de área de efeito com tratamento rigoroso de bordas para prevenção de violações de memória (*buffer overflow*).
* **Sistema de Decisão Multivariável:** Comparação estatística de métricas socioeconômicas utilizando tipagem estendida (`unsigned long int`), cálculos derivados em ponto flutuante e árvores de decisão otimizadas via `switch-case` e operadores ternários, com suporte a grandezas inversamente proporcionais.
